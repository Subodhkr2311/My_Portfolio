## ⚡ Overview

A high-performance personal portfolio built with React 18, Vite, Tailwind CSS, and Framer Motion. Engineered with clean geometric typography (**Plus Jakarta Sans**), smooth glassmorphism, warm ambient glow, and responsive design.

### Key Sections
1. **Overview & Hero**: High-impact introduction highlighting hands-on engineering, product ownership, and systems architecture.
2. **Measurable Outcomes**: Audited production metrics across mobile releases, cross-functional leadership, and cloud backends.
3. **Featured Case Studies**:
   - **FocusAce**: Distraction-free habit engine shipped to Google Play Store (`io.webel.genmoksha`).
   - **Pantry Call**: Corporate order queue and dispatch platform on Google Play Store (`com.webelio.pantry`).
   - **Civic Issue Resolution Platform**: Smart India Hackathon 1st Rank winning platform with spatial clustering.
   - **LLM Evaluation Studio & SFT Harness**: Independent research framework for post-training benchmark evaluation and hallucination detection.
4. **The 6-Stage Process**: Interactive SDLC lifecycle from problem discovery through store deployment.
5. **Career History**: Professional experience at Ethara AI, Webel.io Digitals, and Hoffero.
6. **Services & Education**: Consulting capabilities, B.Tech CSE (88.8% aggregate, GD Goenka University), and honors.
7. **Contact**: Streamlined direct inquiry channels (Email, LinkedIn, GitHub).
